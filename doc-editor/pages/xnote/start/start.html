简介
你正在查看的是 XNote 的使用文档，通过此文档，你可以快速的创建一个功能丰富的编辑器并接入到你的项目中。
如果你想要从零开始创建一个完全自定义编辑器，请阅读：开发者文档。
XNote 是 Textbus 官方开发的一个功能丰富的富文本编辑器，可作为普通的富文本编辑器使用，也可接入协作服务，让多人在线实时共享编辑。我们还会不定时的添加更多新的有趣的功能，记得一定要常回来看看。
创建编辑器
安装依赖：
npm install @textbus/xnote katex
原生接入
准备一个 DOM 元素作为编辑器容器。
<div id="box"></div>
HTML
实例化编辑器：
import { Editor } from '@textbus/xnote'
import 'katex/dist/katex.css'
import '@textbus/xnote/bundles/index.css'

const box = document.getElementById('box')

const editor = new Editor()
editor.mount(box).then(() => {
  console.log('XNote 创建完成。')
})

Vue 项目接入
<script setup lang="ts">
import { onMounted, ref } from 'vue'
import { Editor } from '@textbus/xnote'
import 'katex/dist/katex.css'
import '@textbus/xnote/bundles/index.css'

const editorRef = ref()
const editor = new Editor()
onMounted(() => {
  editor.mount(editorRef.value).then(() => {
    console.log('编辑器创建完成')
  })
})

onUnmouted(() => {
  editor.destroy()
})
</script>
<template>
  <div ref="editorRef" class="editor">

  </div>
</template>

React 项目接入
import { useEffect } from 'react'
import { Editor } from '@textbus/xnote'
import 'katex/dist/katex.css'
import '@textbus/xnote/bundles/index.css'

function App() {
  const editorRef = useRef()
  useEffect(() => {
    const editor = new Editor()
    editor.mount(editorRef.current).then(() => {
      console.log('编辑器创建完成')
    })
    return () => {
      editor.destroy()
    }
  }, [])

  return (
    <div ref={editorRef}></div>
  )
}

Angular 项目接入
import { Component, ElementRef, ViewChild, AfterViewInit, OnDestroy } '@angular/core'
import { Editor } from '@textbus/xnote'
import 'katex/dist/katex.css'
import '@textbus/xnote/bundles/index.css'

@Component({
  selector: 'my-editor',
  template: '<div #editorRef></div>'
})
export class EditorComponent implements AfterViewInit, OnDestroy {
  @ViewChild('editorRef') editorRef: ElementRef;
 
  editor = new Editor()
  ngAfterViewInit(): void {
    this.editor.mount(this.editorRef.nativeElement).then(() => {
      console.log('编辑器创建完成')
    })
  }

  ngOnDestroy() {
    this.editor.destroy()
  }
}

配置项
XNote  继承自 Textbus，并在 Textbus 配置项的基础上增加了以下配置。
/**
 * XNote 配置项
 */
export interface EditorConfig extends TextbusConfig {
  /** 默认 HTML 内容*/
  content?: string,
  /** 协作服务配置 */
  collaborateConfig?: XNoteCollaborateConfig,
  /** 视图配置项 */
  viewOptions?: Partial<ViewOptions>
}

工具条
XNote 默认创建一个行内工具条和左侧快捷工具，我们还提供了静态工具条和悬浮工具条，你可以通过配置项覆盖默认的工具条配置。
import {
  InlineToolbarPlugin,
  LeftToolbarPlugin,
  StaticToolbarPlugin,
  SuspensionToolbarPlugin,
  Editor
} from '@textbus/xnote'

// 行内工具条，会根据用户的框选自动弹出
const inlineToolbarPlugin = new InlineToolbarPlugin({
  // 主题：可选，可配置 dark，默认为 light
  theme: 'light'
})

// 左侧工具条，会根据用户的鼠标指针，自动在文档左侧弹出操作
const leftToolbarPlugin = new LeftToolbarPlugin()

// 静态工具条，适用于普通编辑器顶部的工具条
const staticToolbarPlugin = new StaticToolbarPlugin({
  // 静态工具条需要一个放置工具的容器，
  host: document.getElementById('toolbar'),
  // 主题：可选，可配置 dark，默认为 light
  theme: 'light'
})

// 悬浮工具条，会根据用户的滚动，自动展示在文档可视区域的顶部
const suspensionToolbarPlugin = new SuspensionToolbarPlugin({
  // 主题：可选，可配置 dark，默认为 light
  theme: 'light'
})

const editor = new Editor({
  plugins: [
    inlineToolbarPlugin,
    leftToolbarPlugin,
    staticToolbarPlugin,
    suspensionToolbarPlugin
  ]
})
